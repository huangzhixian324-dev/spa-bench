# SPATBench

**SPATBench: Methodological Choices Can Outweigh Algorithmic Choices in
Transcriptomic Immunotherapy Prediction Benchmarking at Current Sample Sizes**

An open-source, Docker-reproducible benchmark framework that isolates three
benchmarking design choices across six prediction methods and five
immunotherapy-treated cohorts (196 patients; melanoma, NSCLC, bladder):

1. **Response definition** collapses rankings: on the same Riaz 2017 patients,
   switching from the gene-defined cytolytic surrogate to clinical RECIST v1.1
   drops ElasticNet-Var from 0.985 to 0.465 and GEP from 0.968 to 0.503, while
   IMPRES (no feature overlap) is nearly insensitive. The between-endpoint
   effect is 3.5x the largest within-endpoint method gap (Liu 2019 and
   IMvigor210 replications use the same author-constructed surrogate).
2. **Feature selection** rewrites the biological narrative: variance- vs
   MI-based selection yields 27%-overlapping gene sets (2.4% without the
   shared prescreen) at indistinguishable performance.
3. **Circularity Detection Score (CDS)**: a null-referenced pre-benchmarking
   diagnostic (v1.2.1; source in `cds_tool/` and at github.com/huangzhixian324-dev/cds);
   the validated
   deliverable is a reporting convention whose binding rule is declaring the
   endpoint-defining genes, with CDS as the quantitative companion.

High-resolution validation: ElasticNet (MI) on Gide 2019 (n = 73) becomes
FDR-significant at 5,000 full-pipeline shuffles (p = 0.0232, within-cohort
BH q = 0.028). No trainable method survives FDR on any clinical endpoint at
n <= 43.

## Repository layout

- `scripts/` - all analysis scripts (every reported number is regenerated by
  a named script and recorded with git commit, seeds, and split-file digests
  in `results/run_registry.json`)
- `results/benchmark/v33/` - machine-readable outputs (benchmark_v33.json,
  permutation_v33.json with the complete 36-cell matrix, per-cell checkpoint
  files in `nc_cells/`, power_table_v33.json, bh_sensitivity_v33.json)
- `results/figures/v33/` - all figures (300 DPI)
- `docs/` - manuscript source (`manuscript_v34.md`; typeset Cell Systems v35),
  supplementary material, submission PDFs
- `cds_tool/` - the CDS package source (v1.2.1)
- `data/` - cohort data and preprocessing provenance
- `Dockerfile` - container image (spa-bench:v33)

## Verification

```bash
pip install -r requirements.txt
python scripts/run_all_checks.py     # 12 checks: deps -> self-test -> results -> figures -> docs -> audit
```
Exit code 0 means every check passed. Individual checks can be run directly,
e.g. `python scripts/validate.py` (end-to-end synthetic self-test) or
`python scripts/audit_archive.py` (integrity audit of the packaged archive).

## Reproduction

```bash
docker build -t spa-bench:v33 .
docker run spa-bench:v33 python -W ignore scripts/validate.py   # synthetic validation, exit 0
# full result regeneration (requires the Zenodo-archived inputs):
docker run -v $PWD/results:/app/results spa-bench:v33 python -W ignore scripts/rerun_v33.py
```

Results are deterministic under seed 42 (k-fold stability over seeds 42..51
in Table S12). The Docker image reproduces the synthetic validation test;
regenerating the reported tables additionally requires the Zenodo-archived
inputs and `scripts/rerun_v33.py`.
